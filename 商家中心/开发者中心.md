# 开发者中心

> **说明**：开发者中心仅介绍 API Key 的申请与回调配置流程，接口参数、错误码、签名机制等详细 API 文档请查阅独立的 **《API 接入文档》**。

## API管理

**功能描述**：管理所有已创建并申请了API权限的商家/应用。

![API管理](./images/开发者中心_API管理_1.png)

**操作**：

- **创建API Secret**：创建好API key给到技术进行技术对接。该密钥请妥善管理，如有泄露风险，请尽快替换。

![API管理](./images/开发者中心_API管理_2.png)

- **Webhooks回调**：技术参数配置，根据业务勾选对应事件。

![API管理](./images/开发者中心_API管理_3.png)

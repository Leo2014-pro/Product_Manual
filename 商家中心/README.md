# 商家中心

商家中心是平台的核心操作后台，涵盖资产管理、收付款、U卡发卡、承兑、VA账户、卡收单、报表、系统管理和开发者对接等全部功能模块。

## 功能模块

| 模块 | 文档 | 说明 |
|------|------|------|
| 资产中心 | [资产中心.md](资产中心.md) | 资产账户、充提、转入转出、受益人管理、费率、承兑 |
| 收款 | [收款.md](收款.md) | 支付链接、数币收款订单、法币收款订单 |
| 付款 | [付款.md](付款.md) | 数币付款订单、法币付款订单 |
| 承兑订单 | [承兑订单.md](承兑订单.md) | OSL承兑账户、收款、付款、交易对手、订单管理 |
| U卡管理 | [U卡管理.md](U卡管理.md) | U卡账户、共享项目、卡片管理、3DS验证、交易查询、持卡人 |
| VA账户 | [VA账户.md](VA账户.md) | 用户管理、账户管理、交易查询、认证记录、创建记录 |
| 卡收单 | [卡收单.md](卡收单.md) | 卡收款订单、退款订单、争议订单 |
| 报表管理 | [报表管理.md](报表管理.md) | 业务报告生成 |
| 系统管理 | [系统管理.md](系统管理.md) | 用户管理、角色管理、安全中心 |
| 开发者中心 | [开发者中心.md](开发者中心.md) | API Key管理、Webhooks回调 |
